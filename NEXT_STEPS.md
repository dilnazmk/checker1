# Local quick start

1. Install Node.js 22.16 or newer.
2. Run `npm ci` and copy `.env.example` to `.env`.
3. Set the Cloudflare credentials in `.env` to enable assignment analysis.
4. Run `npm run dev` and open http://localhost:5173.
5. Run `npm test` and `npm run test:e2e` to validate workflows.

See [README.md](README.md) for architecture and compatibility, and [DEPLOYMENT.md](DEPLOYMENT.md) for deployment. No changes have been published or deployed automatically.
